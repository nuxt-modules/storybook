This module comes with a default Storybook configuration file to provide the best possible user experience.

## Default configuration

```ts [main.ts]
import { defineMain } from '@storybook-vue/nuxt/node'

export default defineMain({
  stories: [
    '../stories/**/*.mdx',
    '../stories/**/*.stories.@(js|jsx|mjs|ts|tsx)',
  ],
  addons: [
    '@storybook/addon-links',
    '@storybook/addon-docs',
  ],
  framework: {
    name: '@storybook-vue/nuxt',
    options: {},
  },
})
```

You can learn more about the [Storybook configuration](https://storybook.js.org/docs/configure).

## Overwriting the configuration

You can extend the default configuration:

::tip{type="info"}

This config has the highest priority to overwrite the defaults and [storybook.config](#config-option).

::

## CSF Factories

[CSF Factories](https://storybook.js.org/docs/api/csf/csf-next) are supported. Import `defineMain` from `@storybook-vue/nuxt/node` and `definePreview` from `@storybook-vue/nuxt`: the Nuxt preview is added to your addons, and `parameters.nuxt` is typed in the preview, metas and stories.

Install `@storybook-vue/nuxt` next to `@nuxtjs/storybook` so your project can import it. Storybook's codemod writes these imports for you:

```bash
npx storybook automigrate csf-factories
```

::code-group

```ts [.storybook/main.ts]
import { defineMain } from '@storybook-vue/nuxt/node'

export default defineMain({
  stories: ['../components/**/*.stories.ts'],
  addons: ['@storybook/addon-docs'],
  framework: '@storybook-vue/nuxt',
})
```

```ts [.storybook/preview.ts]
import addonDocs from '@storybook/addon-docs'
import { definePreview } from '@storybook-vue/nuxt'

export default definePreview({
  addons: [addonDocs()],
})
```

```ts [components/MyRuntimeConfig.stories.ts]
import preview from '../.storybook/preview'
import MyRuntimeConfig from './MyRuntimeConfig.vue'

const meta = preview.meta({ component: MyRuntimeConfig })

export const Staging = meta.story({
  parameters: {
    nuxt: {
      runtimeConfig: { public: { apiBase: 'https://staging.example.com' } },
    },
  },
})
```

::

::tip{type="info"}

With `definePreview`, Storybook only loads the preview annotations listed in `addons`, so add the addons whose preview you use (such as `addonDocs()`) there as well as in `main.ts`.

::
