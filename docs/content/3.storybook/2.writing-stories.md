---
title: Writing stories
description: Render your components in a Nuxt app, and configure it per story with parameters.nuxt.
---

Stories are written like in any [Storybook project](https://storybook.js.org/docs/writing-stories). The framework renders each of them in its own Nuxt app, so your components can use auto-imports, plugins, composables such as `useRoute()` or `useRuntimeConfig()`, and Nuxt components such as `<NuxtLink>`.

```ts twoslash [components/MyGreeting.stories.ts]
// @allowArbitraryExtensions
// @filename: .storybook/preview.ts
import { definePreview } from '@storybook-vue/nuxt'
export default definePreview({})
// @filename: components/MyGreeting.d.vue.ts
import type { DefineComponent } from 'vue'
declare const MyGreeting: DefineComponent<{ name: string }>
export default MyGreeting
// @filename: components/MyGreeting.stories.ts
// ---cut---
import preview from '../.storybook/preview'
import MyGreeting from './MyGreeting.vue'

const meta = preview.meta({ component: MyGreeting })

export const Default = meta.story({
  args: { name: 'Nuxt' },
})
```

## `parameters.nuxt`

Configure the Nuxt app of a story, a story file or every story (in `.storybook/preview.ts`) with `parameters.nuxt`. It is typed with [CSF Factories](/storybook/config#csf-factories).

### `route`

The route the app starts on.

- **type**: `string`
- **default**: `'/'`

```ts twoslash [components/MyBreadcrumbs.stories.ts]
// @allowArbitraryExtensions
// @filename: .storybook/preview.ts
import { definePreview } from '@storybook-vue/nuxt'
export default definePreview({})
// @filename: components/MyBreadcrumbs.d.vue.ts
import type { DefineComponent } from 'vue'
declare const MyBreadcrumbs: DefineComponent<{}>
export default MyBreadcrumbs
// @filename: components/MyBreadcrumbs.stories.ts
import preview from '../.storybook/preview'
import MyBreadcrumbs from './MyBreadcrumbs.vue'
const meta = preview.meta({ component: MyBreadcrumbs })
// ---cut---
export const Settings = meta.story({
  parameters: {
    nuxt: { route: '/settings?tab=profile' },
  },
})
```

### `navigation`

Lets the story navigate away from its route, in the router or to another site. When `false`, the story stays where it is, and each attempt is reported to the `navigation` spy: see [Navigation](/storybook/mocking#navigation).

- **type**: `boolean`
- **default**: `false`

### `runtimeConfig`

Values deep-merged into the runtime config of your Nuxt app for a specific story.

- **type**: a partial runtime config

```ts twoslash [components/MyApiStatus.stories.ts]
// @allowArbitraryExtensions
// @filename: .storybook/preview.ts
import { definePreview } from '@storybook-vue/nuxt'
export default definePreview({})
// @filename: components/MyApiStatus.d.vue.ts
import type { DefineComponent } from 'vue'
declare const MyApiStatus: DefineComponent<{}>
export default MyApiStatus
// @filename: components/MyApiStatus.stories.ts
import preview from '../.storybook/preview'
import MyApiStatus from './MyApiStatus.vue'
const meta = preview.meta({ component: MyApiStatus })
// ---cut---
export const Staging = meta.story({
  parameters: {
    nuxt: {
      runtimeConfig: { public: { apiBase: 'https://staging.example.com' } },
    },
  },
})
```

### `endpoints`

Endpoints answered from inside the preview for this story, keyed by URL. See [`registerEndpoint`](/storybook/mocking#registerendpoint).

- **type**: `Record<string, Endpoint>`
