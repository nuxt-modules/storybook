title: Configuration
description: Configure Storybook with the @storybook-vue/nuxt framework.
---

Storybook reads its configuration from `.storybook/main.ts` and `.storybook/preview.ts`. Set `@storybook-vue/nuxt` as the framework of `main.ts`: it loads your Nuxt app into Storybook. You can learn more about the [Storybook configuration](https://storybook.js.org/docs/configure).

## CSF Factories

[CSF Factories](https://storybook.js.org/docs/api/csf/csf-next) are the recommended way to write the configuration and the stories. Import `defineMain` from `@storybook-vue/nuxt/node` and `definePreview` from `@storybook-vue/nuxt`: the Nuxt preview is added to your addons, and [`parameters.nuxt`](/storybook/writing-stories#parametersnuxt) is typed in the preview, metas and stories. Hover the code below to see the types.

::code-group

```ts twoslash [.storybook/main.ts]
import { defineMain } from '@storybook-vue/nuxt/node'

export default defineMain({
  stories: ['../components/**/*.stories.ts'],
  addons: ['@storybook/addon-docs'],
  framework: '@storybook-vue/nuxt',
})
```

```ts twoslash [.storybook/preview.ts]
import addonDocs from '@storybook/addon-docs'
import { definePreview } from '@storybook-vue/nuxt'

export default definePreview({
  addons: [addonDocs()],
})
```

```ts twoslash [components/MyButton.stories.ts]
// @allowArbitraryExtensions
// @filename: .storybook/preview.ts
import { definePreview } from '@storybook-vue/nuxt'
export default definePreview({})
// @filename: components/MyButton.d.vue.ts
import type { DefineComponent } from 'vue'
declare const MyButton: DefineComponent<{ label: string; primary?: boolean }>
export default MyButton
// @filename: components/MyButton.stories.ts
// ---cut---
import preview from '../.storybook/preview'
import MyButton from './MyButton.vue'

const meta = preview.meta({ component: MyButton })

export const Primary = meta.story({
  args: { label: 'Button', primary: true },
})
```

::

::tip{type="info"}
With `definePreview`, Storybook only loads the preview annotations listed in `addons`, so add the addons whose preview you use (such as `addonDocs()`) there as well as in `main.ts`.
::

If your stories use CSF3, Storybook's codemod moves the configuration and the stories to CSF Factories:

```bash
npx storybook automigrate csf-factories
```

CSF3 stories keep working: type them with the `Meta` and `StoryObj` types exported by `@storybook-vue/nuxt`.

## Framework options

Pass options to the framework with its object form:

```ts twoslash [.storybook/main.ts]
import { defineMain } from '@storybook-vue/nuxt/node'

export default defineMain({
  stories: ['../components/**/*.stories.ts'],
  framework: {
    name: '@storybook-vue/nuxt',
    options: {
      docgen: 'vue-component-meta',
    },
  },
})
```

- `storyHooks`: the annotations running in the context of their story, for the [spies of mocked auto-imports](/storybook/mocking#spies).

  - **type**: `string[]`
  - **default**: `['afterEach', 'beforeEach', 'loaders', 'play']`

- The options of [`@storybook/vue3-vite`](https://storybook.js.org/docs/get-started/frameworks/vue3-vite#options), such as `docgen`.

## Vite config

The framework merges the Vite config of your Nuxt app into the one of Storybook. You can modify the configuration with Storybook `viteFinal` preset, which runs after the Nuxt config is applied:

```ts twoslash [.storybook/main.ts]
import { defineMain } from '@storybook-vue/nuxt/node'

export default defineMain({
  framework: '@storybook-vue/nuxt',
  stories: ['../components/**/*.stories.ts'],
  viteFinal: (config) => ({
    ...config,
    optimizeDeps: {
      ...config.optimizeDeps,
      include: [...(config.optimizeDeps?.include ?? []), 'my-cjs-dependency'],
    },
  }),
})
```

Vite dependency discovery is disabled (`optimizeDeps.noDiscovery`), so add the dependencies that need pre-bundling to `optimizeDeps.include`.
