---
title: Storybook Viewer
description: Visualize your Stories inside DevTools tab.
---

The Nuxt module serves Storybook from the Nuxt dev server under the `/_storybook/` route, allowing you to quickly visualize your Storybook ✨

Change the path with the [`route` option](/nuxt-module/options).

You can also open Storybook alongside your application in the Nuxt DevTools.

![Devtools Viewer](/devtools-viewer.png)

If something goes wrong, please report the issue to [Storybook Labs](https://github.com/storybookjs/labs), the repository hosting the Storybook Vite Plugin.
