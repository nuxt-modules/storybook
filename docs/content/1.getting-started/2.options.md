---
title: Options
description: Configuration options for the Nuxt Storybook module.
---

Configure Nuxt Storybook with the `storybook` property.

```ts [nuxt.config.ts]
export default {
  // Defaults options
  storybook: {
    route: '/_storybook',
  },
}
```

- `enabled`: Enable or disable the module. This can be useful to control and disable storybook in layers or in extended projects.

  - **type**: `boolean`
  - **default**: `true`

- `route`: The route where the Nuxt dev server serves the Storybook application.

  - **type**: `string`
  - **default**: `/_storybook`

- `logLevel`: Log level for the terminal output.

  - **type**: `number`
  - **default**: `nuxt.options.logLevel`

Storybook runs inside the Nuxt dev server through [`@storybook/vite-plugin`](https://www.npmjs.com/package/@storybook/vite-plugin), so it shares the host, port and HTTPS settings of `nuxt dev`.
