## Installation

The Storybook CLI provides a convenient way to integrate Storybook with Nuxt. Run the following command in your project's root directory:

::code-group

```bash [pnpm]
pnpm dlx storybook@next init
```

```bash [yarn]
yarn dlx storybook@next init
```

```bash [npm]
npx storybook@next init
```

::

This command installs Storybook along with the Nuxt module, sets up the scripts and configuration files, and adds some boilerplate stories to get you started.
Please check the [Storybook documentation](https://storybook.js.org/docs/get-started/install) for more information.

::warning
Storybook 11 is published under the `next` tag until its release: `storybook@latest` still installs Storybook 10, which only works with v10 of the module.
::

Alternatively, you can install Storybook and the Nuxt module manually.

1. Add `@nuxtjs/storybook` as a development dependency to your project:

::code-group

```bash [nuxi]
npx nuxi@latest module add storybook
```

```bash [pnpm]
pnpm i -D @nuxtjs/storybook @storybook-vue/nuxt storybook@next
```

```bash [yarn]
yarn add -D @nuxtjs/storybook @storybook-vue/nuxt storybook@next
```

```bash [npm]
npm install -D @nuxtjs/storybook @storybook-vue/nuxt storybook@next
```

::

2. If not using `nuxi` above, add the module `@nuxtjs/storybook` to your Nuxt configuration:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxtjs/storybook'],
})
```

3. Create the [Storybook config files](#storybook-config-files).

::tip{type="success"}
That's it! You can now use Storybook in your Nuxt app ✨
::

The manual installation method is useful if you want to use a specific version of Storybook. The following versions of Storybook are compatible with the Nuxt module:

| Module Version | Storybook | Nuxt | Node.js |
|----------------|-----------|------|---------|
| v11.x | 11.x | 4.x / 5.x | 22+ |
| v10.x | 10.x | 3.18.1+ / 4.x | 22+ |
| v9.x | 8.x / 9.x | 3.x | 20+ |
| v4.x | 6.x | 2.x | |

Upgrading from v10? See the [migration guide](/getting-started/migration).

## Usage

When you run your Nuxt app in development mode, Storybook is served by the Nuxt dev server itself, on the same host and port, under `/_storybook/` by default. The URL is displayed in the console.

If you want to start Storybook without running your Nuxt app, you can use the following command:

::code-group

```bash [pnpm]
pnpm storybook
```

```bash [yarn]
yarn storybook
```

```bash [npm]
npm run storybook
```

```bash [manual]
storybook dev -p 6006
```

::

When you install Storybook using the CLI, you will find a few stories in the `stories` directory to get you started. You can add your own stories to this directory or create a new directory for your stories (in which case you will need to update the [Storybook configuration](/storybook/config)).
The Storybook server will automatically detect changes to your stories and update the UI accordingly.

::tip{type="info"}
Discover your Stories directly within the `Storybook Devtools tab`.
::

For more information on how to write stories and the next steps, refer to the [Storybook documentation](https://storybook.js.org/docs/get-started/whats-a-story).

### Preview Builds

You can test the latest code from the `main` branch using `pkg.pr.new`, without waiting for a stable npm release.

#### Opting in to preview builds

To use the latest preview version, follow these steps:

- Modify the `@nuxtjs/storybook` dependency in your `package.json`:

  ```json
  {
    "devDependencies": {
      "@nuxtjs/storybook": "https://pkg.pr.new/@nuxtjs/storybook@main"
    }
  }
  ```

- Remove the lockfile and reinstall dependencies so the preview build is resolved.

Every pull request is also published to `pkg.pr.new`, so you can test a specific PR with:

```json
{
  "devDependencies": {
    "@nuxtjs/storybook": "https://pkg.pr.new/@nuxtjs/storybook@<pr-number>"
  }
}
```

#### Opting out of preview builds

If you need to revert to the stable release, follow these steps:

- Change the `@nuxtjs/storybook` dependency in `package.json` back to the stable version:

  ```json
  {
    "devDependencies": {
      "@nuxtjs/storybook": "next"
    }
  }
  ```

- Remove the lockfile and reinstall the dependencies to revert to the stable release.

## Storybook config Files

When running `nuxt dev`, this module looks for these files:

- `.storybook/main.{ts,js}`
- `.storybook/preview.{ts,js}`

::code-group

```ts twoslash [.storybook/main.ts]
import { defineMain } from '@storybook-vue/nuxt/node'

export default defineMain({
  stories: ['../components/**/*.stories.ts'],
  addons: ['@storybook/addon-docs'],
  framework: '@storybook-vue/nuxt',
})
```

```ts twoslash [.storybook/preview.ts]
import addonDocs from '@storybook/addon-docs'
import { definePreview } from '@storybook-vue/nuxt'

export default definePreview({
  addons: [addonDocs()],
})
```

::

See the [Storybook configuration](/storybook/config) for the details.

## Module options

You can customize the Nuxt module's behavior by using the `storybook` property in `nuxt.config`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  storybook: {
    // Options
    route: '/_storybook',
  },
})
```

See the [module options](/nuxt-module/options).
