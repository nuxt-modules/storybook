---
title: 'TypeScript'
description: 'Guide on how to use TypeScript with the Nuxt module'
---

To use the Nuxt module with TypeScript, ensure that imports typically from `@storybook/*` are now replaced by imports from `@nuxtjs/storybook` (or `@storybook-vue/nuxt` if the Nuxt module is not used). This is needed since the Storybook packages are dependencies of the Nuxt module, and are not directly installed in the project.

With [CSF Factories](https://storybook.js.org/docs/api/csf/csf-next), the types come from the factories: `defineMain` types `.storybook/main.ts`, `definePreview` types `.storybook/preview.ts`, and `preview.meta()` and `meta.story()` infer the component props in your stories. Install `@storybook-vue/nuxt` next to `@nuxtjs/storybook` so your project can import it.

::code-group

```typescript [.storybook/main.ts]
import { defineMain } from '@storybook-vue/nuxt/node'

export default defineMain({
  stories: ['../components/**/*.stories.ts'],
  addons: ['@storybook/addon-docs'],
  framework: '@storybook-vue/nuxt',
})
```

```typescript [.storybook/preview.ts]
import addonDocs from '@storybook/addon-docs'
import { definePreview } from '@storybook-vue/nuxt'

export default definePreview({
  addons: [addonDocs()],
})
```

```typescript [components/Button.stories.ts]
import preview from '../.storybook/preview'
import Button from './Button.vue'

const meta = preview.meta({
  title: 'Example/Button',
  component: Button,
})

export const Primary = meta.story({
  args: {
    primary: true,
    label: 'Button',
  },
})
```
